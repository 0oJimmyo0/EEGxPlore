# Historical selective recipe audit

This checklist documents the rejected-paper candidate family; it is not a
launch prerequisite. `historical_selective` is permanently non-launchable in
the active ICASSP profile because the original checkpoint and complete raw
recipe are unavailable. The current implementation maps that label to the
existing AttnRes-plus-typed-specialist parameter family only for archival
interpretation, not as a claim that it reproduces run family `1785556`.

The machine-readable target is
`historical_recipe_1785556.json`; the matched-family report is generated by
`audit_historical_bundle.py`. They document what is missing but cannot
authorize a new paper-facing run. The rejected-manuscript SEED-V rows are
stored separately as `legacy_reported_paper` evidence and are eligible only
with an explicit legacy label. Use the paper-derived protocol files and
`selective_paper` for new paper-facing selective runs. The locked
`fresh_selective_recipe.json` remains an independent archived recipe.

- Historical source: `docs/17576_Depth_Aware_Selective_Ad.pdf`, Tables 8, 10, and 13
